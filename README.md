# 🤖 IIT Chatbot Demo

This is a simple AI-powered chatbot built for integration with an IIT college website. It uses OpenAI's GPT model to answer queries about college-related information such as admissions, departments, and events.

---

## 🌟 Features

- Responsive chatbot UI using HTML, CSS, and JavaScript
- Python Flask backend with REST API
- GPT-3.5 powered intelligent conversation via OpenAI API
- Easy to customize for any college or institute
- Clean and modular project structure

---

## 🚀 Technologies Used

- HTML, CSS, JavaScript (Frontend)
- Python + Flask (Backend)
- OpenAI GPT-3.5 API
- REST API Integration
